# Neon Glow Audio Equalizer Visualizer

An animated pure CSS multi-frequency audio equalizer visualizer component with neon gradient spectrum bars and rhythmic equalizer height animations.

## 1. What does this do?
- Simulates real-time multi-band audio spectrum bars using pure CSS keyframe height transformations and staggered animation delays.
- Features glowing neon gradients (cyan to purple to magenta) with dynamic drop-shadow intensity pulsing.
- Incorporates glassmorphic audio player controls, track status tags, and high-fidelity telemetry metrics.

## 2. How is it used?
- Include `style.css` in your application or integrate `.equalizer-wrapper` rules into your audio player components.
- Copy the markup from `demo.html` to add visual spectrum feedback to web audio players, podcast cards, or music streaming dashboards.

## 3. Why is it useful?
- Delivers an engaging, visual audio feedback animation without consuming CPU cycles for JavaScript canvas rendering.
- Staggered animation delays yield believable organic spectrum movement.
- Highly customizable spectrum colors, bar counts, and pulse speeds.
