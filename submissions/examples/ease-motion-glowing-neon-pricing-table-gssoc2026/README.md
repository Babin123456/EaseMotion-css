# EaseMotion Glowing Neon Cyberpunk Pricing Table Component

An interactive SaaS Pricing Table featuring animated cyberpunk neon glowing borders, elevated featured plan hierarchy, and spring-elastic hover cards.

## 1. What does this do?
- Displays pricing tiers in a responsive side-by-side grid layout.
- Highlights featured subscription plans using animated gradient neon borders (`neon-glow-border`).
- Utilizes CSS cubic-bezier elastic spring curves to scale and lift cards when focused or hovered.

## 2. How is it used?
- Add `style.css` to your HTML file.
- Structure plans using `.price-card` and add the `.featured` class for primary plans.
- Customize neon colors with CSS variables (`--neon-cyan`, `--neon-pink`).

## 3. Why is it useful?
- High-Converting SaaS UI: Draws immediate user focus toward primary subscription tiers.
- Lightweight & Dependable: Pure CSS implementation with zero external JS dependencies.
- Fully Accessible: Formatted with high-contrast text ratios and scalable typography.
