# EaseMotion Interactive Bento Grid Showcase Component

An asymmetrical, high-density Bento Grid layout featuring glassmorphism surfaces, dynamic hover elevation, animated SVG/chart visuals, and responsive flex/grid transitions.

## 1. What does this do?
- Displays feature items in a modern asymmetrical grid layout (`bento-large`, `bento-tall`, `bento-wide`).
- Animates visual sub-elements (chart bar scaling and shield icon rotation) on card focus/hover.
- Provides subtle glowing borders using cubic-bezier spring curves.

## 2. How is it used?
- Include `style.css` in your HTML file.
- Apply grid layout container class `.bento-grid` and position elements using `.bento-large`, `.bento-tall`, or `.bento-wide`.
- Adjust grid gap and row heights via standard CSS variables.

## 3. Why is it useful?
- Modern Dashboard Aesthetics: Perfect for feature showcase sections, tech portfolios, and SaaS landing pages.
- Zero JS Overhead: Driven entirely by native CSS Grid and transition keyframes.
- Fully Mobile Adaptive: Smoothly collapses from 4-column to 2-column and single-column layouts.
