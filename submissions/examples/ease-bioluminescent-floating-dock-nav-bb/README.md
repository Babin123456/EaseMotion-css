# Bioluminescent Floating Dock Nav

A floating pill navigation menu featuring proximity neon glow waves, tooltip popovers, and glass reflection.

## 1. What does this do?
This component renders a floating biological navigation dock pill with neon glow indicators, tooltips, and smooth scale elevation micro-interactions on hover and focus.

## 2. How is it used?
Link `style.css` in your webpage and structure your floating dock HTML:

```html
<link rel="stylesheet" href="style.css">

<nav class="bio-dock">
  <a href="#" class="bio-item active">
    <span class="tooltip">Dashboard</span>
    <span class="icon">🏠</span>
  </a>
</nav>
```

## 3. Why is it useful?
It provides modern SaaS platforms, mobile web apps, and personal portfolio sites with a sleek floating pill navigation experience without JavaScript dependencies.
