# EaseMotion Morphing Liquid Wave Button Component

An interactive pure CSS Morphing Liquid Wave Button featuring organic rotating border-radius liquid fills, multi-layered gradient wave depths, and spring-elastic hover responses.

## 1. What does this do?
- Creates an organic fluid liquid wave fill inside button containers.
- Uses rotating CSS `border-radius: 40%` shapes (`rotateLiquid` `@keyframes`) to simulate real-time liquid turbulence.
- Rises and fills the button background on user hover using cubic-bezier fluid transitions.

## 2. How is it used?
- Import `style.css` into your stylesheet or component layout.
- Wrap CTA text inside `<a class="liquid-btn">` containing child `.liquid-wave` layer elements.
- Adjust wave rise speeds by altering the `transition: top` and `animation-duration` parameters.

## 3. Why is it useful?
- High-Conversion CTA Component: Grabs user attention with tactile fluid motion feedback.
- Pure CSS Solution: Achieves organic liquid motion without heavy JavaScript canvas scripts.
- Multi-Theme Capable: Includes pre-configured cyan/blue and purple/pink gradient color palettes.
