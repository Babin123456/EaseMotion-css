# Morphing Glassmorphic Step Stepper

A responsive multi-step checkout stepper component built with glassmorphism panels, active node pulse rings, dynamic connector line flows, and completed step badges.

## 1. What does this do?
- Displays a wizard checkout stepper with completed, active, and pending step nodes.
- Animates active nodes with expanding pulse rings and scale transformations.
- Provides glowing connector line animations indicating progress through complex workflows.

## 2. How is it used?
- Import `style.css` into your project codebase.
- Use the HTML markup structure from `demo.html` to integrate step indicators into checkout flows, onboarding wizards, or form sequences.

## 3. Why is it useful?
- Delivers an intuitive visual progress guide for multi-step tasks.
- Lightweight, pure CSS layout with no JavaScript overhead.
- Accessible contrast ratios and responsive flexbox alignment.
