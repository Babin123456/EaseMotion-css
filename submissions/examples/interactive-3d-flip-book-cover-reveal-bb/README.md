# Interactive 3D Flip Book Cover Reveal

An interactive 3D perspective book cover reveal component featuring realistic hardcover opening transformations, interior page text previews, and gold foil typography details.

## 1. What does this do?
- Animates a 3D book cover opening 140 degrees on hover using CSS `transform-style: preserve-3d` and `rotateY` keyframes.
- Reveals interior book pages complete with chapter excerpts, pagination, and realistic spine inner shadow effects.

## 2. How is it used?
- Import `style.css` into your web project.
- Embed the HTML markup from `demo.html` to display interactive book previews for digital bookstores, reading apps, or portfolio project cards.

## 3. Why is it useful?
- Delivers an engaging physical book feel in digital web browsers without requiring 3D canvas/WebGL frameworks.
- Hardware accelerated 60fps CSS 3D matrix transitions.
