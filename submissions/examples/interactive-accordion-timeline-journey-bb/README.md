# Interactive Accordion Timeline Journey

An interactive vertical accordion roadmap timeline component featuring milestone node line indicators, glassmorphic card containers, date tags, and smooth chevron rotations.

## 1. What does this do?
- Displays milestone roadmap timelines with vertical connector line paths and glowing milestone nodes.
- Integrates expanding accordion card details for company roadmaps, release notes, or project history logs.

## 2. How is it used?
- Include `style.css` in your stylesheets.
- Copy the HTML structure from `demo.html` to display interactive timeline milestones on about pages or product release logs.

## 3. Why is it useful?
- Delivers an intuitive timeline visualization format for project histories and product roadmaps.
- Clean pure CSS flex layout, accessible design tokens, and smooth card transitions.
