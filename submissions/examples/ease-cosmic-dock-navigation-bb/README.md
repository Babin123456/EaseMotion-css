# Cosmic Dock Navigation

A floating glassmorphic orbital dock bar with starfield particle aura, active planet rings, and tooltip popups.

## 1. What does this do?
This component renders a floating orbital dock navigation bar with rotating planet target rings, popover tooltips, and smooth scale elevation transitions on focus or hover.

## 2. How is it used?
Link `style.css` in your webpage and embed the cosmic dock markup:

```html
<link rel="stylesheet" href="style.css">

<nav class="cosmic-dock">
  <a href="#" class="dock-node active">
    <span class="tooltip">Solar Core</span>
    <span class="icon">☀️</span>
    <div class="orbital-ring"></div>
  </a>
</nav>
```

## 3. Why is it useful?
It provides web applications, space theme landing pages, and developer portfolio sites with a futuristic floating menu experience without requiring external JavaScript dependencies.
