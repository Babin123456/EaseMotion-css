# Cyberpunk Glitch Status Badge

A micro-interaction status pill component featuring clip-path glitch displacement, scanline overlays, and neon pulse aura.

## 1. What does this do?
This component renders cybernetic system status badges that display glowing pulse indicators and trigger RGB glitch text slice animations on hover or focus.

## 2. How is it used?
Link `style.css` in your webpage and embed the status badge structure:

```html
<link rel="stylesheet" href="style.css">

<div class="glitch-badge badge-green" role="status">
  <span class="badge-dot"></span>
  <span class="badge-text" data-text="SYSTEM OPERATIONAL">SYSTEM OPERATIONAL</span>
  <span class="badge-code">SYS_OK</span>
</div>
```

## 3. Why is it useful?
It provides gaming dashboards, sci-fi applications, and DevOps status pages with futuristic micro-interaction badges without JavaScript libraries.
