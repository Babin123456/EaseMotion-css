# Bioluminescent Jellyfish Bell Pulse

A bio-inspired fluid loader component featuring elastic umbrella bell contraction keyframes, trailing neon tentacles, and glowing particle shockwave aura.

## 1. What does this do?
This component renders an interactive bioluminescent jellyfish loader widget that contracts and expands rhythmically using pure CSS keyframes, backdrop blur filters, and undulating tentacle waves.

## 2. How is it used?
Link `style.css` in your webpage and insert the jellyfish loader structure:

```html
<link rel="stylesheet" href="style.css">

<div class="jellyfish-card">
  <div class="jelly-bell"></div>
  <div class="tentacles">
    <div class="tentacle t1"></div>
  </div>
</div>
```

## 3. Why is it useful?
It provides web applications, gaming landing pages, and creative dashboards with a hypnotic, organic loader animation without requiring heavy WebGL or Canvas canvas overhead.
