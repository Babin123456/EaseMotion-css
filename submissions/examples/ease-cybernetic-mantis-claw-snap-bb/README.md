# Cybernetic Mantis Claw Snap

A high-speed biomechanical action button featuring sharp scissor-lock keyframe snaps, laser sights, and cybernetic spark bursts.

## 1. What does this do?
This component renders a sci-fi gaming action button with animated mantis claw blades that snap together around the center label on hover and focus events.

## 2. How is it used?
Link `style.css` in your webpage and embed the mantis button markup:

```html
<link rel="stylesheet" href="style.css">

<button class="mantis-btn" type="button">
  <div class="claw claw-left"></div>
  <div class="claw claw-right"></div>
  <div class="btn-core">ENGAGE LOCK</div>
</button>
```

## 3. Why is it useful?
It provides gaming interfaces, Web3 applications, and interactive tech landing pages with tactile, biomechanical button interactions without JavaScript libraries.
