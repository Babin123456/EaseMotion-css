# 3D Perspective Card Deck

An interactive stacked 3D tilt card deck featuring depth offsets, sheen highlights, and smooth focus elevation keyframes.

## 1. What does this do?
This component renders an interactive 3D perspective stacked card deck where cards elevate, tilt forward, and glow when hovered or focused using keyboard controls.

## 2. How is it used?
Link `style.css` in your webpage and embed the card deck container:

```html
<link rel="stylesheet" href="style.css">

<div class="deck-container">
  <article class="p-card card-top">
    <div class="sheen"></div>
    <div class="card-content">
      <h2>Card Title</h2>
    </div>
  </article>
</div>
```

## 3. Why is it useful?
It provides Web3 applications, gaming dashboards, and fintech interfaces with modern 3D depth elevation cards without requiring JavaScript libraries.
