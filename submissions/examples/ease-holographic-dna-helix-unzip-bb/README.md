# Holographic DNA Helix Unzip

An interactive 3D double helix loader featuring base-pair unzipping keyframe transitions, chromatic glowing nodes, and glass backdrop elevation.

## 1. What does this do?
This component renders an interactive holographic DNA strand widget whose base-pair rungs unzip and separate dynamically when hovered or focused.

## 2. How is it used?
Link `style.css` in your webpage and embed the DNA helix markup:

```html
<link rel="stylesheet" href="style.css">

<div class="dna-card">
  <div class="helix-container">
    <div class="rung r1">
      <span class="node n-left">A</span>
      <span class="strand-bar"></span>
      <span class="node n-right">T</span>
    </div>
  </div>
</div>
```

## 3. Why is it useful?
It provides biotech platforms, scientific data visualizers, and Web3 dashboards with a futuristic 3D biological loader without JavaScript dependencies.
