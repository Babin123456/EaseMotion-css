# Biometric Retinal Scanner HUD

A sci-fi security authentication card with iris targeting reticles, vertical laser beam sweep keyframes, and biometric status indicators.

## 1. What does this do?
This component renders an interactive biometric retinal scanning card widget with rotating aperture target rings and laser sweep keyframe overlays.

## 2. How is it used?
Link `style.css` in your webpage and insert the biometric scanner card:

```html
<link rel="stylesheet" href="style.css">

<div class="scanner-card">
  <div class="hud-aperture">
    <div class="outer-ring"></div>
    <div class="scan-laser"></div>
  </div>
</div>
```

## 3. Why is it useful?
It provides security platforms, Web3 identity verification flows, and sci-fi gaming dashboards with biometric authentication UI elements without JavaScript overhead.
